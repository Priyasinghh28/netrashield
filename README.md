# NetraShield 

> **"Faces can be forged. Human behavior cannot."**

AI-powered behavioral fraud defense for modern banking systems.

##  About the Project

NetraShield is a cybersecurity landing page built for a banking hackathon. It demonstrates how behavioral biometrics can detect fraud **before** credentials are abused — even when attackers have valid usernames and passwords.

Traditional fraud detection fails against:
- Deepfake video KYC bypass
- Voice cloning attacks
- OTP theft via SIM swapping
- Session hijacking

NetraShield solves this by analyzing **how** a user behaves, not just **who** they claim to be.

##  Key Features

- **Behavioral Biometrics Engine** — typing rhythm, mouse movement, device fingerprint, navigation patterns
- **Real-time Fraud Simulation** — live trust score meter with AI verdict output
- **SOC Dashboard** — live threat feed, metrics, and system health indicators
- **Attack Vector Library** — deepfakes, OTP theft, voice cloning, session hijacking
- **Future Roadmap** — quantum-ready auth, autonomous fraud response, cross-bank threat intel

##  Problem Statement

Banks lose **$485 billion annually** to fraud. Existing systems rely on credentials that can be stolen, faces that can be cloned, and OTPs that can be intercepted. NetraShield shifts the detection layer to behavioral biometrics — invisible to attackers, impossible to replicate.
